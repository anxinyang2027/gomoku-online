## 一、总体设计

**视觉风格**：深色背景 + 木质棋盘的“棋馆风”。主色调建议：

| 用途 | 颜色 | 说明 |
|---|---|---|
| 页面背景 | `#2B2B2B` 深灰 | 沉稳，衬托棋盘 |
| 棋盘 | `#E8C286` 木色 | Canvas 绘制 |
| 黑子 / 白子 | `#1A1A1A` / `#F8F8F8` | 带径向渐变高光 |
| 强调色 | `#C0392B` 朱红 | 按钮、胜利提示 |

**布局策略**：移动端优先（和截图一样的竖屏布局），整个页面居中限制在 `max-width: 480px`，PC 打开时两侧留黑边，一套样式通吃。

## 三、对局页（核心页面）

```
┌───────────────────────────────┐
│ ←退出      ⏱ 03:24      规则  │
│───────────────────────────────│
│  ● 黑方（你）         ○ 白方    │
│───────────────────────────────│
│                               │
│         ┌───────────┐        │
│         │           │        │
│         │  15×15    │        │
│         │  棋盘区    │        │
│         │ (Canvas)  │        │
│         │           │        │
│         └───────────┘        │
│                               │
│───────────────────────────────│
│  当前回合 ●黑方落子   第 12 手  │
│  [ 悔棋 ]   [ 求和 ]   [ 认输 ] │
└───────────────────────────────┘
```

**交互细节：**
- **落子**：PC 上鼠标 hover 显示半透明预览棋子，点击确认落子；移动端直接点击。落子有缩放动画 + 音效
- **最后一手标记**：最新棋子上加红点，方便对局双方看
- **胜利判定**：五连棋子高亮闪烁 + 红线贯穿 → 延迟 0.5s 弹结算框
- **棋盘自适应**：Canvas 尺寸随屏幕 `vw` 缩放，内部坐标做等比换算
- **模式差异**：本地双人为默认；挑战 AI / 在线模式下，等对方落子时锁盘并显示“等待对方…”

**结算弹窗（复用组件）：**

```

        │      ● 黑方胜利！    │
        │                     │
```

## 五、与开发阶段的对应关系

| 页面/功能 | 一期（本地双人） | 二期（接后端） | 三期（用户系统） | 四期（在线对战） |
|---|---|---|---|---|
| 首页 | 只亮“本地双人” | — | 显示昵称积分，激活登录 | 激活在线模式 |
| 对局页 | JS 判定胜负 | 判定走后端 API | — | 锁盘/等待状态 |
| 结算弹窗 | ✅ | 记入对局记录 | 加积分变动 | — |
| 登录页 | 不需要 | 不需要 | ✅ | — |
| 排行榜/战绩 | 不需要 | 战绩查询 | ✅ | 排名实时更新 |

这样设计的好处是：**页面骨架一期就全部搭好，后续每期只是“点亮”功能**，不用推翻重来。

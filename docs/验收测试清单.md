## 一、页面闭环(M3.12)

从首页开始,按真实使用路径走一遍:

- [ ] 首页:用户条显示"游客 · 点击登录";在线模式 / 人机对战两张卡置灰带"敬请期待"角标;**本地双人**宽卡可点;底部导航"首页"高亮
- [ ] 点置灰卡片 → 无任何反应
- [ ] 点"本地双人" → 进入对局页,棋盘为空、计时 00:00 开始走、"当前回合 ●黑方落子 · 第 0 手"
- [ ] 随意下完一盘 → 结算弹窗 → [返回] → 回到首页
- [ ] 再进一局 → 结算 → [再来一局] → 棋盘清空、计时归零、状态栏"第 0 手"、悔棋置灰(此项即 M4.4 的洁净检查)
- [ ] 排行榜页 / 战绩页:显示"暂无数据 · 等待后端接入";排行榜页底部有"我的排名:—"占位栏
- [ ] 登录页:空提交 → toast 报错;填好提交 → toast"三期开放";点"没有账号?注册" → 标题和按钮切换为注册
- [ ] 底部导航:排行榜页高亮"排行榜"、战绩页高亮"战绩";点"首页"能回来;点"设置"弹设置弹窗(不跳页)

## 二、棋盘表现(M1.15)

- [ ] PC 缩放 100% 和 150% 下,网格线、星位、棋子边缘都清晰不发糊
- [ ] 鼠标悬停空格点 → 半透明预览子;移开消失;已占格点不显示预览;换手后预览颜色跟着变
- [ ] 故意点在交叉点偏一点的位置 → 落子必中最近交叉点
- [ ] 最后一手棋子上有朱红小点
- [ ] 拖动浏览器窗口改变大小 → 棋盘自适应重绘,棋子/红点位置不乱
- [ ] 设备模拟选高分屏机型(如 Pixel,dpr≈3):线条与棋子依然清晰

## 三、对局逻辑(M2.15)

胜负判定,四个方向各真赢一次:

- [ ] **横向**五连:五子白描边 + 朱红贯穿线,闪烁 3 轮定格 → 0.5 秒后弹结算"● 黑方胜利!"
- [ ] **竖向**五连 → 同上,胜方文案正确
- [ ] **斜向 ↘** 五连 → 同上
- [ ] **斜向 ↗** 五连 → 同上
- [ ] 故意下出**六连**(过五不断)→ 依然正确判胜

其他链路:

- [ ] 计时:进对局页即开始;切到别的标签页 1 分钟再回来 → 时间依然准确(不漂移);对局结束停表定格
- [ ] 悔棋:点一下 → 最后一手消失、执子方回退、状态栏手数 -1;落第一手前按钮置灰;对局结束后置灰
- [ ] 求和:确认弹窗 → [同意求和] → 按平局结算;[取消] → 继续对局
- [ ] 认输:确认 → 当前执子方判负,结算文案正确
- [ ] 对局中点 [← 退出] → 二次确认弹窗;[继续对局] 能留下;对局已结束或一手未下时点退出 → 直接回首页
- [ ] 平局:可不测(需下满 225 手);代码逻辑为 `history.length === 225` 判平,信任实现即可

## 四、复盘模式(M4.1 回归)

- [ ] 结算弹窗 [复盘] 可点 → 底部切换为复盘面板,从终局画面开始,"第 N / N 手"
- [ ] [上一步] 逐步回退,退到空盘时按钮置灰
- [ ] [下一步] 逐手前进,新落的手有缩放动画;到终局时按钮置灰
- [ ] [退出复盘] → 恢复终局画面 + 五连高亮 → 结算弹窗再次弹出
- [ ] 结算弹窗 [再来一局] → 复盘面板隐藏、对局面板恢复、一切归零

## 五、音效与设置

- [ ] 落子有短促"嗒"声,黑白子音效一致
- [ ] 首页 ⚙ 或导航"设置" → 关闭音效 → 落子无声;重新打开 → 恢复
- [ ] 关掉设置、刷新页面 → 开关状态保留(localStorage)

- [ ] 落子准(点交叉点附近必中)、无 300ms 延迟
- [ ] 落子动画流畅、最后一手红点清晰
- [ ] 音效正常(首次落子即有声音,不被浏览器拦截)
- [ ] 结算 → 复盘 → 再来一局,全程顺手不卡
